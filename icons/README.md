# Extension icons

Flaticon **file zipper** PNGs at the sizes Chrome expects:

| File         | Use                    |
|-------------|-------------------------|
| `icon16.png`  | Toolbar                 |
| `icon32.png`  | Toolbar (retina)        |
| `icon48.png`  | `chrome://extensions`   |
| `icon128.png` | Chrome Web Store        |

`icon48.png` is resized from the 128×128 asset if you don’t have a native 48×48.

## Attribution

Flaticon free use usually requires **attribution** in your store listing.

## Replacing

Overwrite the four `icon*.png` files and reload at `chrome://extensions`.
